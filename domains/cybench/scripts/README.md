# Cybench Challenge Conversion Script

This script converts cybench challenges from the inspect_eval format to the SABER agentic benchmarking framework format. Run it from the repository root with `uv run python domains/cybench/scripts/convert_cybench_to_saber.py <challenge_name>` where `<challenge_name>` is the challenge directory name (e.g., `labyrinth_linguist`). The script automatically searches for the challenge source in `external/inspect_evals/src/inspect_evals/cybench/challenges/` and outputs converted files to `domains/cybench/`. You can override these paths using `--source-base` and `--target-base` arguments if needed. The script will generate task configurations, prompt templates, docker files, and copy solution files while fixing line endings for Unix compatibility.
